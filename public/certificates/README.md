Drop certificate PDFs or image files in this folder. Supported formats: PDF, PNG, JPG, JPEG, WebP, AVIF, and SVG.

The portfolio picks them up automatically during the next build. Use a clear file name such as `semester-1-topper.pdf` or `python-course-certificate.jpg`; that name becomes the preview card title. Clicking a card opens the PDF or image in the portfolio preview.
